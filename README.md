# 📊 Курсы ЦБ РФ — Google Apps Script

Скрипт для Google Таблиц, который получает актуальные курсы валют с сайта Центрального банка России и записывает их прямо в таблицу. Запускается одной кнопкой из меню.

---

## Возможности

- Получает курсы **USD, EUR, CNY, GBP, JPY** (список настраивается)
- Запрос к бесплатному XML API ЦБ РФ — **без ключа и регистрации**
- Записывает структурированную таблицу: код, название, курс за 1 единицу, номинал
- Фиксирует время последнего обновления в ячейке `F1`
- Обрабатывает ошибки: сетевые сбои, неверный HTTP-статус, битый XML

## Быстрый старт

### 1. Создайте скрипт в Google Таблице

1. Откройте Google Таблицу (новую или существующую)
2. Перейдите в меню **Расширения → Apps Script**
3. Удалите весь код в редакторе и вставьте содержимое файла `Code.gs`
4. Нажмите **Сохранить** (Ctrl+S / Cmd+S)

### 2. Запустите скрипт

1. Вернитесь в таблицу и **обновите страницу** — появится меню «Курсы ЦБ»
2. Выберите **Курсы ЦБ → Обновить курсы**
3. При первом запуске Google запросит разрешения — нажмите «Разрешить»

### 3. Результат

| A | B | C | D |
|---|---|---|---|
| Валюта | Название | Курс (руб.) | Единиц |
| USD | Доллар США | 89.1234 | 1 |
| EUR | Евро | 96.5678 | 1 |
| CNY | Китайский юань | 12.3456 | 1 |
| ... | ... | ... | ... |

Время последнего обновления записывается в ячейку **F1**.

## Настройка

### Изменить список валют

В начале файла `Code.gs` найдите константу и добавьте нужные коды:

```javascript
const CURRENCIES = ['USD', 'EUR', 'CNY', 'GBP', 'JPY'];
```

Полный список доступных кодов — в ответе API: `cbr.ru/scripts/XML_daily.asp`

### Автоматический запуск по расписанию

Вместо ручного запуска можно настроить триггер в Apps Script:

1. В редакторе скрипта нажмите **Триггеры** (значок часов) → **Добавить триггер**
2. Функция: `fetchCbrRates`, источник события: **По времени**, интервал: например, каждый день в 10:00

## Как работает скрипт

```
Клик в меню
     │
     ▼
UrlFetchApp.fetch(API_URL)    ← HTTP GET к cbr.ru
     │
     ├─ Ошибка сети?          → пишем в A1 и выходим
     ├─ HTTP ≠ 200?            → пишем в A1 и выходим
     │
     ▼
XmlService.parse(xml)         ← разбираем XML
     │
     ├─ Битый XML?             → пишем в A1 и выходим
     │
     ▼
Фильтруем по CURRENCIES[]     ← берём только нужные валюты
     │
     ▼
value / nominal               ← пересчёт за 1 единицу (важно для JPY: номинал = 100)
     │
     ▼
sheet.getRange().setValues()  ← записываем строки в таблицу
     │
     ▼
F1 ← время обновления
```

### Почему `getContentText('windows-1251')`?

ЦБ РФ отдаёт XML в кодировке **Windows-1251**. Без явного указания Apps Script читает ответ как UTF-8, и кириллица в названиях валют превращается в кракозябры. Передача кодировки вторым аргументом решает проблему.

### Почему `value / nominal`?

ЦБ РФ публикует курс за `Nominal` единиц валюты. Например, для японской иены `Nominal = 100`, то есть в ответе API указан курс за 100 иен. Деление на `Nominal` даёт курс за 1 единицу — это удобнее для расчётов.

## Обработка ошибок

| Сценарий | Поведение |
|---|---|
| Сеть недоступна | Текст ошибки в ячейку A1, выход |
| Сервер вернул не 200 | HTTP-статус в A1, выход |
| XML не распарсился | Текст исключения в A1, выход |
| Нужные валюты не найдены | Предупреждение в A1, выход |
| Всё ок | Данные в строки 2–N, время в F1 |
